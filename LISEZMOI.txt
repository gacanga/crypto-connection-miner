Crypto Connection Miner 0.5.0 - mineur GPU multi-coins pour NVIDIA. Sans frais de développeur. (S'appelait
GostMiner jusqu'à la 0.4.0.)
  --algo gostd   (par défaut)  GOSTcoin (GST)
  --algo lyra2v2               Bitmark (MARKS) et autres coins Lyra2REv2

Cartes NVIDIA de Maxwell (GTX 900) à Blackwell (RTX 50), Windows 10/11 x64 et Linux x86-64 (glibc 2.34 ou plus).
Pilote : un pilote NVIDIA récent (support CUDA 12.9 pour les cartes les plus récentes).

Le plus simple : modifiez puis lancez start_gostcoin.bat / start_gostcoin.sh (GOSTcoin) ou start_bitmark.bat /
start_bitmark.sh (Bitmark) : mettez votre adresse dans ADDRESS. Ils minent sur la pool Crypto Connection
(crypto-connection.net, 1 % de frais de pool) et relancent le mineur automatiquement. Statistiques :
https://crypto-connection.net

Ligne de commande :
  GOSTcoin, Windows : crypto-connection-miner.exe --user VOTRE_ADRESSE_GST.rig1
  GOSTcoin, Linux :   ./crypto-connection-miner --user VOTRE_ADRESSE_GST.rig1
  Bitmark,  Windows : crypto-connection-miner.exe --algo lyra2v2 --user VOTRE_ADRESSE_MARKS.rig1
  Bitmark,  Linux :   ./crypto-connection-miner --algo lyra2v2 --user VOTRE_ADRESSE_MARKS.rig1
  Avec --user et sans --pool, le mineur se connecte à la pool Crypto Connection : crypto-connection.net port 4033
  (GOSTcoin) ou 4043 (Bitmark). Toute autre pool stratum : ajoutez --pool HOTE:PORT (et --pass x).

Options : --algo (gostd ou lyra2v2), --pool HOTE:PORT, --user ADRESSE.WORKER (--pass d=64 demande une difficulté
fixe à la pool), --gpus 0,1,2 (cartes), --kernel N (gostd : variante forcée ; par défaut chaque carte mesure les
5 variantes 3 s et garde la plus rapide), --intensity N (lyra2v2 : 2^N hashs par lancement ; par défaut 22 jusqu'à
20 SM, 23-24 au-delà, limité par la mémoire de la carte), --stats S, --log FICHIER, --selftest (test.bat / test.sh
testent les deux algos), --bench S.
Solo sur un wallet GOSTcoin local (getwork, gostd) : --conf gostcoin.conf --port 8795.

Contrôles : au démarrage, le mineur vérifie ses références CPU sur de vrais blocs (GOSTcoin : bloc genèse,
identifiant d'une coinbase, racine merkle ; Bitmark : hash du bloc 2490869, sa preuve de travail lyra2rev2 et sa
racine merkle). S'il affiche WRONG, ne pas miner. L'autotest GPU lyra2v2 doit retrouver le nonce du bloc Bitmark
2490869. Chaque résultat GPU est revérifié sur le CPU avant envoi.

Erreurs CUDA : si une carte signale une erreur CUDA, le mineur écrit les derniers messages de la pool dans le log et
quitte avec le code 3 ; les scripts de lancement le relancent après 5 s.

Overclocking (gostd) : sur P104-100 / GTX 10xx, un overclock du cœur (+100 ou +200 MHz) a provoqué des erreurs
« illegal memory access » lors de nos essais ; avec le cœur d'origine, aucune. Laissez le cœur d'origine (un
décalage mémoire ne pose pas de problème) et baissez-le si l'erreur apparaît.

Vitesse typique sur une P104-100 (classe GTX 1070) à 160 W, cœur d'origine : gostd 21-23 MH/s, lyra2v2 36-37 MH/s.
